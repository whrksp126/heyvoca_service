# 실험실 '내 농장 꾸미기' 계약 (2026-11-25)

타이니팜식 아이소메트릭 농장 홈. **실험실 토글 `farm_home` 을 켠 사용자에게만** 노출한다.
그림은 임시 자산으로 시작하고, 나중에 AI 생성 스프라이트로 **파일만 교체**한다(코드 수정 없이).

## 1. 아이템 카탈로그 (백엔드 정본: `heyvoca_back/app/data/farm_catalog.json`)

```json
{ "id": "tree_round", "category": "tree", "name": "둥근 나무",
  "w": 1, "h": 1, "price_gem": 5,
  "unlock": null,                // 또는 {"type":"streak","value":7} | {"type":"words_learned","value":500}
  "starter_qty": 2 }             // 처음 지급 수량(0이면 없음)
```

category: `field`(단어장 밭) · `crop`(작물 종류, 배치 아님) · `tree` · `fence` · `deco` · `animal` · `ground`

초기 목록(id / 크기 / 가격 / 해금 / 처음 지급):
- crop(밭에 심는 작물 종류, 가격 0, 배치 불가): carrot, corn, rice, cucumber, tomato, pumpkin, radish, strawberry
- field: `field` 3×3 — 단어장 밭. 단어장 1개당 1개, 수량 제한은 단어장 수
- tree: tree_round 1×1 5보석 starter 2 · tree_pine 1×1 5 · tree_apple 1×1 12
- fence: fence_wood 1×1 1보석 starter 8 · fence_stone 1×1 2
- deco: scarecrow 1×1 8 starter 1 · mailbox 1×1 6 starter 1 · bench 1×1 6 · well 1×1 15 · flower_bed 1×1 4 · lamp 1×1 6 · signboard 1×1 5 · windmill 2×2 40 (words_learned 500)
- ground: path_tile 1×1 1 · pond 2×2 20
- animal: chicken 1×1 starter 1 · sheep 1×1 25 · cat 1×1 20 · dog 1×1 0 (streak 7) · cow 1×1 0 (streak 30)

해금 조건이 있고 가격 0인 아이템은 조건 달성 시 1개 **자동 지급**(멱등).

## 2. 사용자 DB (heyvoca_user, `migrations/`)

- `user_farm_layout` — user_id PK, `layout` JSON, `version` int, `updated_at`
  - layout 항목: `{ "uid": "문자열", "item_id": "tree_round", "x": 3, "y": 5, "flip": false, "book_id": 12|null }`
  - 격자 크기 24×24 (0..23). 밭(`field`)은 `book_id` 필수
- `user_farm_inventory` — (user_id, item_id) PK, `qty` int (보유 총수. 배치 수 ≤ qty)
- `user_voca_book.crop_type` VARCHAR(20) NULL — NULL이면 carrot

## 3. 사전 DB (heyvoca_dict, `migrations_dict/`)

- 서점 단어장(어드민이 서점에 내는 단어장 모델)에 `crop_type` VARCHAR(20) NULL 추가
- 사용자가 서점 단어장을 담을 때 `user_voca_book.crop_type` 에 복사
- 어드민 단어장 편집 API·화면에서 crop_type 선택 가능

## 4. API (모두 `@token_required`)

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/farm/state` | `{catalog, inventory:{item_id:qty}, layout, version, books:[{id,name,crop_type,word_count,stages:{seed,sprout,...}}], gem, stats:{streak, words_learned}}` — 처음 호출 시 starter 지급 + 단어장 밭 자동 배치(겹치지 않게), 해금 지급 |
| PUT | `/farm/layout` | body `{layout, version}` → 검증(보유 수량·격자 범위·겹침·밭 book_id 소유) 후 저장, version+1. version 불일치 409 |
| POST | `/farm/shop/buy` | body `{item_id}` → 기존 `change_gem` 단일 경로로 차감(User 먼저 잠금), inventory+1. 보석 부족 400 |
| PATCH | `/farm/books/<id>/crop` | body `{crop_type}` → 본인 단어장만 |

`stages` 는 기존 작물 XP 단계(씨앗~수확 5단계) 기준 단어 수 집계. 기존 함수 재사용.

## 5. 실험실 토글

기존 lab settings 에 `farm_home`(기본 false) 추가. 백엔드 허용 키 목록 + 프론트 `LabNewFullSheet` 항목:
제목 "내 농장 꾸미기", 설명 "홈을 꾸밀 수 있는 농장으로 바꿔요".

## 6. 프론트 화면

- `pixi.js` v8, 농장 화면만 동적 import(초기 번들 영향 없음)
- `farm_home` on → 홈 본문이 FarmHome 으로 교체. 상단 칩([언어]…[불꽃][보석])은 유지, 기존 오늘 할 일 카드는 하단 접이식으로
- 농장: 2:1 아이소 격자 타일 64×32, 확대(두 손가락, 0.6~2.0)·이동(끌기), 깊이 정렬 x+y
  - 밭: 단어장 밭 3×3, 안에 작물 단계별 스프라이트(단계 분포대로), 탭 → 해당 단어장 열기
  - 동물: 빈 칸으로 천천히 이동 + 통통 튀기, 탭하면 점프
  - 분위기: 구름 그림자 이동, 바람 흔들림(나무·작물 살짝 기울기), 탭 반짝임 파티클
- 꾸미기 모드: 하단 서랍 탭(밭·나무·울타리·장식·땅·동물·상점) → 끌어다 놓기, 놓을 수 없으면 빨간 발판, 뒤집기·보관 버튼, 저장/취소
  - 밭 선택 시 작물 종류 바꾸기(PATCH)
  - 상점 탭: 가격·해금 조건 표시, 구매 → POST buy
- 디자인 토큰·Phosphor 아이콘만, 이모지 금지

## 7. 자산 교체 구조 (중요)

`heyvoca_front/src/assets/farm2/manifest.json` 하나가 모든 그림을 정의:
```json
{ "tile": {"w":64,"h":32},
  "items": { "tree_round": {"src":"tree_round.png","anchor":[0.5,1],"scale":1} },
  "crops": { "carrot": {"stages":["carrot_0.png", "...5개"], "anchor":[0.5,1]} } }
```
임시 자산: 기존 `assets/images/farm/` 그림(당근 단계, field-base 등) 재사용, 없는 건 Pixi Graphics 로 간단한 도형(색·그림자 있는 2.5D 느낌)을 그려 둔다 — manifest 에 `src` 가 없으면 도형 폴백. 나중에 PNG 를 넣고 manifest 만 바꾸면 교체된다.

# v2 변경 (2026-11-25 사용자 피드백) — 이 절이 위 내용보다 우선

## 시점: 아이소메트릭 폐기 → 정면 3/4 탑다운 + 세로 스크롤
- 격자 정사각, 화면 투영은 타일 `w : h = 4 : 3` (가로 그대로, 세로만 0.75 눌림). 회전 없음.
- 맵 **가로 10칸 × 세로 60칸**. 확대 1.0 에서 맵 너비 = 화면 너비. 주 조작은 세로 끌기 스크롤, 핀치 0.8~1.8.
- 깊이 정렬: 물체 발판의 **아래쪽 y** (같으면 x).
- 스프라이트는 정면 3/4 그림 그대로(앵커 하단 중앙 = 발판 아래쪽 가운데).

## 밭 크기 = 단어 수
- 단어 1개 = 밭 칸 1개. 밭 칸 = 타일의 1/2 (타일 1개 = 2×2 칸).
- `cols = clamp(짝수로 올림(ceil(sqrt(n))), 4, 16)`, `rows = max(4, 짝수로 올림(ceil(n / cols)))`
- 발판(타일) = `w = cols/2`, `h = rows/2` (최소 2×2, 최대 가로 8). n=0 이면 4×4칸.
- 백엔드 `/farm/state` 의 `books[]` 에 `cols, rows, fw, fh` 포함. 겹침·범위 검증과 자동 배치는 이 발판으로. `grid: {w:10, h:60}`.
- 칸마다 단어 순서대로 해당 단어의 단계 작물 1개(칸 중앙). 그래서 books[] 에 단계 분포 대신 **단어별 단계 배열** `cells: ["seed","leaf",...]`(길이 n, 단어장 내 순서)도 포함.

## 밭 그림
- `farm2/field_frame.png`: 나무 테두리 9분할(NineSliceSprite) — manifest `field_frame: {src, slice:[l,t,r,b]}`
- `farm2/soil_cell.png`: 갈아 놓은 흙 둔덕 1칸 — 칸마다 반복
- `farm2/grass_tile.png`: 잔디 바닥 반복 텍스처(TilingSprite)
- 파일이 없으면 지금처럼 도형 폴백.

# v3 변경 (2026-11-25 2차 피드백) — v2 의 "정면 3/4 탑다운"은 **폐기**. 이 절이 최우선

사용자: 탑다운은 입체감이 없어 싫다. 타이니팜처럼 입체감 있고 귀여운 아이소메트릭 + z축 깊이.

## 시점·맵
- 아이소메트릭 2:1 (타일 64×32) 복귀. 맵 **40×40**, 자유 이동(상하좌우 끌기) + 핀치 0.6~1.8.
- 땅은 **둥글게 깎인 섬**: 가장자리 모서리를 둥글게(마름모 꼭짓점이 뾰족하지 않게), 아래쪽에 흙 절벽 두께(약 24px, 위는 잔디 테두리·아래로 갈수록 어두운 흙 그라데이션)로 떠 있는 땅. 잔디는 grass_tile 텍스처 + 은은한 명암 얼룩.
- 깊이 정렬: 발판 앞쪽 꼭짓점 기준 (x+y, 같으면 x).

## 밭
- **칸 = 타일 1개.** 단어 1개 = `plot_soil.png` 둔덕 1개(아이소 마름모 흙 둔덕, 두께 있음). 밭 = cols×rows 둔덕 묶음, 둔덕 위 중앙에 그 단어 단계 작물.
- 발판 `fw = cols, fh = rows` (cols 공식은 v2 그대로, 최대 16). 자동 배치는 밭 사이 **1칸 띄움**.
- 단어장 이름 팻말은 밭 뒤쪽 꼭짓점 위.

## 객체 설계 (프론트, 필수)
`Entity` 기본 클래스: `{uid, itemId, x, y, rot(0|90|180|270), footprint()}` + `update(dt)`, `render()`, `hitTest()`, `destroy()`.
- 회전: 90/270 이면 발판 w↔h 교환. 아이소에서 90° 회전 = **좌우 뒤집기(scale.x=-1)**로 표현(그림이 한 축 방향이므로). 꾸미기 모드 버튼 "뒤집기" → **"회전"**.
- `FieldEntity`(둔덕 묶음+작물), `DecorEntity`(나무·장식), `FenceEntity`(회전 + 같은 축 이웃 울타리와 이어지게 정렬, 모서리는 기둥끼리 맞닿음), `AnimalEntity`(상태 기계: idle·walk·peck·happy·sad, 방향(좌/우=뒤집기), 프레임 애니메이션 `AnimatedSprite`, 탭→happy, 오래 방치→sad 등), `CropEntity`(바닥 기준 흔들림 skew·성장 시 톡 튀는 연출).
- 동물 프레임 manifest: `animals.chicken = {frames:["chicken_f0.png"...8개], anchor:[0.5,0.835], scale, states:{walk:[0,1,2,3], idle:[4], peck:[5], happy:[6], sad:[7]}, fps:8}`. 걷기는 프레임 + 이동, 이동 방향에 따라 좌우 뒤집기. 프레임 없는 동물은 기존 방식 폴백.
- layout 항목에 `rot` 저장(기존 `flip` 은 읽을 때 rot=90 으로 간주).

## 새 자산 (farm2/)
`plot_soil.png`(둔덕), `fence_wood_iso.png`(왼아래→오른위 축 울타리), `chicken_f0..7.png`(위 states 순서). grass_tile.png 는 유지. field_frame.png·soil_cell.png 는 미사용.

# v4 변경 (2026-11-26) — 작은 행성 농장. v2·v3 의 평면 맵 렌더링은 폐기, 이 절이 최우선

사용자: 큰 입체 구(행성) 위에 밭을 심고 가꾸기. 세로 화면 OK. 끌어서 행성 회전, 탭으로 조작.

## 렌더링: three.js (pixi.js 제거)
- 동적 import 유지(초기 번들 영향 0). 저사양 기준 Note9 웹뷰. pixelRatio ≤ 2.
- 행성: 구(반지름 R), 잔디 텍스처(grass_tile.png, tint 0xd2d8a2) + 부드러운 음영(Lambert/Toon), 가장자리 대기 림 글로우, 배경은 헤이보카 톤 하늘 그라데이션. 반구광+방향광.
- 카메라: 세로 화면에서 행성이 화면 아래쪽 약 70%를 차지(행성 윗면을 비스듬히 내려다봄). 끌기 = 행성 회전(관성), 핀치 = 거리 확대/축소. 상단 120px·하단 200px UI 여백 고려.
- 탭: raycast → 엔티티 또는 지표면 격자 칸.

## 격자 = 위도·경도 칸
- `grid {w:64, h:32}`(백엔드 응답 값 사용): x → 경도(360°/w), y → 위도 −60°~+60°(120°/h). 칸 중심에 배치. 극지방은 비워 둠(장식용 나무 숲 등 연출 자유).
- 백엔드 layout 모델(x, y, rot, 발판 fw×fh, 겹침 검사)은 **그대로** 사용. 경도 방향은 0↔w-1 이 이어짐(렌더링만; 백엔드는 이음 무시).

## 객체 (v3 Entity 설계 유지)
- 지표면에 서는 그림(작물·나무·장식·동물): 칸 중심에 법선 방향으로 세운 **원통형 빌보드**(법선 축으로만 카메라를 향해 돔), alphaTest, 하단 앵커.
- 밭 둔덕: `plot_soil.png` 를 지표면에 눕힌 데칼(칸마다). 단어 수 많으니 **InstancedMesh**.
- 작물: 단계별 텍스처마다 InstancedMesh + 빌보드 셰이더 권장(300칸 이상), 바람 흔들림은 셰이더에서 바닥 고정 skew.
- 울타리: **3D 저폴리 나무 기둥+가로대 메시**(나무색, 둥근 모서리 느낌) — rot 로 진짜 회전, 같은 축 이웃과 이어짐.
- 동물: 빌보드 + 프레임 애니(chicken_f0~7, states walk 0-3·idle 4·peck 5·happy 6·sad 7, anchor y 0.835, fps 8). 지표면 대원 경로로 걷고, 화면상 이동 방향에 따라 좌우 뒤집기. 탭 → happy.
- 꾸미기 모드: 서랍에서 아이템 선택 → 지표 탭/끌어서 배치, 발판 칸을 초록/빨강 데칼로 표시, 회전 버튼(rot 90° 단위), 저장. 밭 이름 팻말은 밭 위에 떠 있는 작은 라벨.

# v5 변경 (2026-11-26) — 행성 폐기. three.js 는 유지하되 "아이소메트릭 평면 대지". 이 절이 최우선

사용자: 행성은 별로. 타이니팜식으로 복귀하되 기본 대지를 화면 전체를 다 채울 만큼 아주 넓게, 확대·축소하며 원하는 곳(또는 초기 영역)에 밭을 두고 꾸미기.

- 카메라: **OrthographicCamera** 고정 아이소 각도(수평 45°, 내려다보기 약 35°) — 회전 없음. 끌기 = 이동(관성), 핀치 = 확대/축소(넓게 보기 ~ 둔덕 하나가 손가락만 하게). 처음엔 초기 영역(밭들이 자동 배치된 중앙부)이 화면을 채우게.
- 대지: 격자 `grid {w:64, h:64}` 의 **큰 평면**, 화면 어디에도 대지 끝이 안 보일 만큼 넓게 보이게(맵 바깥도 잔디가 이어지고 아주 멀리서 숲·안개로 페이드). 잔디 grass_tile 반복 + 밝고 화사한 헤이보카 톤(형광·올리브 금지), 은은한 명암 얼룩.
- 엔티티는 v4 의 Entity 구조 재사용, 위치만 구면 → 평면(x,y 칸 중심). 행성 관련 코드 삭제.
  - 작물·나무·장식·동물: 카메라를 향한 세운 스프라이트(아이소 그림 그대로 보이게), 하단 앵커, 깊이는 z-buffer + alphaTest.
  - 밭 둔덕: plot_soil.png 를 칸마다 **촘촘히**(둔덕끼리 거의 맞닿게) — 아이소 그림이므로 바닥에 눕히지 말고 카메라를 향한 스프라이트로 칸 중심에. InstancedMesh.

# v8 변경 (2026-11-26) — 자유 모양 밭(칸 집합). 최우선

- 밭 = **칸 집합**. 필요 칸 수 `N = max(4, ceil(word_count / 4))` (칸 하나에 작물 최대 4개, 2×2). 사용자는 N 칸을 **전부** 써서 직사각형·정사각형·ㄱ·ㄷ 등 원하는 모양을 만든다. 조건: 칸 수 == N, 4방향으로 모두 이어짐(한 덩어리), 격자(40×40) 안, 다른 밭과 칸 겹침 없음(밭 사이 간격 규칙은 폐기).
- layout field 항목: `{uid, item_id:"field", book_id, x, y, cells:[[dx,dy],...]}` — cells 는 (x,y) 기준 상대 좌표. cells 가 없으면 서버가 N 칸짜리 가장 정사각형에 가까운 직사각형으로 생성해 채워 준다(GET 시 멱등). 단어 수가 바뀌어 N 이 달라지면 GET 시 모양을 직사각형으로 다시 만든다(멱등, 위치 x,y 유지 시도).
- books[] 에 `cells_needed: N` 추가.
- 렌더링: 칸마다 같은 높이의 평평한 이랑 흙 윗면, **흙 단층(옆면) 없음**. 외곽 둘레에만 일정 두께의 테두리(단어장 색). 밭 크기와 무관하게 테두리 두께·높이 동일. 작물은 칸당 최대 4개.
- 옮기기: 잡은 밭은 위로 들어 올려(약 24px + 그림자) 아래 칸 스냅 예상 위치(초록/빨강)가 잘 보이게.
- 모양 편집(길게 누르기 메뉴 "모양 바꾸기"): 격자 위에서 칸 탭으로 추가/제거(이어진 칸만), 상단 바에 "N칸 중 k칸" 표시, k==N 이고 한 덩어리일 때만 완료 활성. 빠른 버튼: 가로 늘리기/줄이기로 직사각형 자동 재구성.
