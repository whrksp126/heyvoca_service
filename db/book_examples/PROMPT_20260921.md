# 예문 생성 작업 지침 (고정 프롬프트 — 모든 배치 동일)

영어 단어 학습 앱 "헤이보카"의 사전에 **예문이 없는 단어/구(phrase)** 에 예문을 채운다.
입력 배치 파일은 JSON 배열이고 각 항목은 아래 형태다.

```json
{"voca_id": 777, "word": "proofread", "pron": "ˈpruːfriːd",
 "meanings": ["교정보다", "교정을 보다"], "book_meanings": ["교정보다"]}
```

- `book_meanings` = 단어장이 이 단어에 부여한 뜻(가장 중요, 예문은 반드시 이 뜻으로).
- `meanings` = 참고용 사전 뜻 전체.
- 대부분 TOEIC(비즈니스·직장·일상 업무) 단어장에서 온 구(phrase)다. 문맥도 그에 맞춰라.

## 출력

입력과 **같은 순서, 같은 개수**로 아래 형식의 JSON 배열만 출력 파일에 쓴다(설명·마크다운 금지).

```json
[{"voca_id": 777, "word": "proofread",
  "examples": [
    {"origin": "Please <strong class=\"target-word\">proofread</strong> the report before sending it to the client.",
     "meaning": "고객에게 보내기 전에 보고서를 <strong class=\"target-word\">교정봐</strong> 주세요."},
    {"origin": "She <strong class=\"target-word\">proofread</strong> every page of the manual twice.",
     "meaning": "그녀는 설명서의 모든 페이지를 두 번씩 <strong class=\"target-word\">교정보았다</strong>."}
  ]}]
```

## 규칙

1. 단어마다 **예문 정확히 2개**. 서로 다른 상황(예: 업무 이메일 / 회의 / 일상)으로.
2. 영어 예문: 자연스러운 현대 영어, 8~16단어, 한 문장. 대상 단어/구가 **반드시 한 번** 등장.
   - 굴절형 허용(applied for, was admitted to, proofreads …).
   - 구가 분리되면(예: `let go` → `let it go`, `have a problem (in) -ing` → `had a problem finding`) 분리된 전체 구간을 하나로 감싼다.
   - 입력 `word` 가 띄어쓰기 없이 붙은 구(`putaway`, `takeawalk`)면 문장에서는 자연스럽게 띄어 쓴다(`put away`, `take a walk`). 검증기는 공백 무시 비교를 지원한다.
   - 입력 표기의 `(in)`, `-ing`, `oneself`, `do` 같은 형식 표시는 실제 문장에선 자연스럽게 실현한다(`by oneself` → `by himself`).
3. 한국어 예문: 영어의 자연스러운 번역(직역 금지, 존댓말/반말 혼용 가능). 반드시 `book_meanings`의 뜻으로 번역.
4. 강조 태그: 영어·한국어 **각각 정확히 1개**의 `<strong class="target-word">…</strong>`.
   - 영어는 대상 단어/구(굴절 포함) 전체를 감싼다.
   - 한국어는 그 뜻에 해당하는 어절(조사·어미 포함 가능: `교정봐`, `지하철을 타고`)을 감싼다.
   - 다른 HTML 태그·마크다운·따옴표 이스케이프 오류 금지.
5. 고유명사·민감한 소재(정치·종교·성·폭력·질병 진단) 금지. 회사/사람 이름은 흔한 것(Ms. Park, the marketing team 등)만.
6. 모르는 구라도 반드시 채운다. 건너뛰기 금지. `voca_id`·`word`는 입력 그대로 복사.
7. 출력은 **압축 JSON**(들여쓰기 없음). 파일에만 쓰고 채팅 답변은 "done N" 한 줄로 끝낸다.

## 절차

1. 배치 파일을 읽는다.
2. 결과를 `out/<배치파일명>` 에 쓴다 (예: `out/batch_003.json`).
3. `python3 validate.py out/<배치파일명>` 을 실행해 `OK` 가 나올 때까지 고친다(에러 메시지에 항목 index가 있다).
4. `OK` 확인 후 "done <개수>" 로 보고한다.
