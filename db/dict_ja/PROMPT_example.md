# 일한사전 예문 한국어화 — 고정 프롬프트 (모든 배치 동일)

일본어 학습 사전 "heyvoca_dict_ja"의 예문에 **한국어 해석**을 붙이고 강조 태그를 단다.
두 가지 변형이 있다. 입출력의 정확한 배치 파일 스키마·경로·검증 규칙은 `BATCH_FORMAT.md`를
따른다. 이 문서는 그 스키마 안에서 "어떻게 번역·생성할지"의 내용 규칙만 다룬다.

공통: 강조 태그는 `<strong class="target-word">…</strong>` 하나만 쓴다. 다른 HTML·마크다운·
따옴표 이스케이프 오류 금지.

---

## 변형 A — 기존 예문 한국어 해석 + 뜻 판정 (Tatoeba 예문)

일본어 원문은 `20_build_examples.py`가 결정론적으로 매칭·강조해 둔 것이다(원문 쪽
`<strong class="target-word">` 위치는 **건드리지 않는다**). 그런데 예문의 약 80%는 "이 단어가 나온다"까지만 알고
**어느 뜻(sense)으로 쓰였는지는 모르고**, 보충 매칭 예문에는 **동형어 오인**(같은 글자지만 다른
단어)이 섞여 있다. 그래서 너는 예문마다 세 가지를 한다:

1. 이 예문에서 표제어가 **뜻목록 중 어느 sense**로 쓰였는지 고른다.
2. 한국어 해석을 쓰고 강조를 1곳 단다.
3. 표제어가 뜻목록 어디에도 해당하지 않는 뜻·동형어로 쓰였거나, 학습 예문으로 부적절하면 **거부**한다.

후리가나·읽기 처리는 이 프롬프트의 일이 아니다(별도 처리).

### 입력 (탭 구분 7컬럼)

`순번  표제어  읽기  뜻목록  일본어원문(강조 있음)  영어참고번역  ko_ref`

```
1	食う	くう	1:먹다|*2:살아가다/생계를 잇다|3:물다(벌레)	これでは<strong class="target-word">食って</strong>いけない。	I can't make a living with this.	-
2	食う	くう	1:먹다|2:살아가다/생계를 잇다|3:물다(벌레)	早く飯を<strong class="target-word">食え</strong>。	Eat your meal quickly.	-
3	上	うえ	1:위|2:윗사람|3:~한 뒤에	この<strong class="target-word">上</strong>なく幸せです。	I couldn't be happier.	-
4	勉強	べんきょう	1:공부/공부하다	昨日は一日中<strong class="target-word">勉強し</strong>ました。	I studied all day yesterday.	어제는 하루 종일 공부했어요.
```

- `뜻목록` = 앞 "뜻 한국어화" 단계 결과. `sense_no:뜻1/뜻2` 를 `|` 로 이었다.
- `*` 가 붙은 sense 는 Tatoeba 색인이 이미 지정한 sense 다. **기본적으로 그대로 따르고, 문맥상
  명백히 틀렸을 때만** 다른 sense 로 바꾼다. `*` 가 없으면 네가 문맥으로 고른다.
- `영어참고번역`·`ko_ref`(Tatoeba 한국어 번역, 드묾)는 문맥 파악용 참고 자료일 뿐, 그대로 옮기지
  않는다(ko_ref 는 품질이 들쭉날쭉하다). 없으면 `-`.

### 출력 — 입력 줄당 정확히 1줄

```
순번|sense_no|한국어해석
순번|X|거부사유
```

```
1|2|이걸로는 <strong class="target-word">먹고살</strong> 수 없다.
2|1|빨리 밥을 <strong class="target-word">먹어</strong>.
3|X|관용구 일부
4|1|어제는 하루 종일 <strong class="target-word">공부했</strong>어요.
```

### sense 판정 · 거부 규칙

1. `sense_no` 는 **뜻목록에 있는 번호 중 하나**만 쓴다(새 번호 금지). 뜻이 여러 개로 읽히면 이
   문장에서 가장 자연스러운 하나.
2. 해석은 **고른 sense 의 뜻**으로 옮긴다(다른 sense 로 새지 않도록). 강조는 그 뜻에 해당하는 어절.
3. 다음이면 `순번|X|사유` 로 거부한다(사유는 한국어 **10자 이내**, 예: `동형어`, `다른 뜻`,
   `관용구 일부`, `복합어 일부`, `부적절 소재`, `문장 불완전`, `번역 불가`):
   - 강조된 부분이 표제어가 아니라 **동형어·다른 단어**다(예: 표제어 `上(うえ)`인데 `この上ない`의
     관용구 일부, `方(ほう)`인데 `方(かた)` 존칭 등).
   - 표제어의 뜻이 뜻목록 **어느 sense 에도 해당하지 않는다**.
   - 강조가 더 큰 복합어·관용구의 일부만 잘라 감싸서 학습 예문으로 오해를 준다.
   - 문장이 학습 예문으로 부적절하다(성적·폭력적·차별적 소재, 문장이 잘렸거나 의미 불명).
4. 거부를 남발하지 않는다. 자연스러운 문장에서 표제어가 뜻목록의 한 뜻으로 쓰였다면 문체가
   구어체거나 조금 길어도 해석한다.

### 해석 규칙

1. **자연스러운 한국어**로 옮긴다. 직역체 금지(일본어 어순·조사를 그대로 따라 옮기지 않는다).
2. **문체**: 존댓말(-세요/-어요/-습니다)과 평서체(-다)를 문맥에 맞게 자유롭게 섞는다.
   대화·안내문은 해요체, 서술·설명문은 -다체가 자연스러운 경우가 많다(기존 영한사전 예문과
   같은 톤). 하나로 통일하려 하지 말고 문장이 자연스러운 쪽을 고른다.
3. **강조는 한국어 해석에 정확히 1곳**. `admin_emphasis` 규칙과 동일:
   - 표제어 뜻에 해당하는 **어절 단위**로 감싼다.
   - 조사는 포함하지 않는다: `공부했어요`는 되지만 `공부했어요.`(마침표 포함)나
     `공부를`(조사 포함)은 안 된다.
   - 어미·활용은 자연스럽게 포함한다: 관형형("조용한 방이다"→"조용한"), 서술형
     ("운행하고 있다"→"운행하고"), 과거형("공부했어요"→"공부했") 등.
   - 조사·조동사 표제어(`より`, `でも` 등)는 대응하는 한국어 조사/어미 자체를 감싼다
     ("돈<strong class="target-word">보다</strong>", "유령<strong class="target-word">이라도</strong>").
   - 여러 후보가 있으면 문장에서 **가장 핵심적인 한 곳**만 고른다.
4. 일본어 원문의 기존 강조 태그는 그대로 두고, 한국어 해석에서만 새로 강조한다(출력에 일본어는 쓰지 않는다).
5. 원문에 없는 내용을 지어내지 않는다. 원문 의미를 그대로, 자연스럽게만 옮긴다.

## 변형 B — 예문 생성 (Tatoeba 예문이 없거나 대표 뜻 예문이 없는 단어용)

예문이 없는 표제어(또는 sense 1 예문이 없는 표제어)에 새 예문을 만든다. 일본어 문장과 한국어
해석을 **둘 다** 새로 쓰고, **양쪽 모두**에 강조 태그를 넣는다.

### 입력 (탭 구분 5컬럼)

`순번  표제어  읽기  JLPT급수  뜻목록`

```
1	忙しい	いそがしい	N4	1:바쁜
2	見送る	みおくる	N2	1:배웅하다/전송하다|2:보류하다/미루다|3:지켜보다
3	経験	けいけん	-	1:경험/경험하다
```

- `JLPT급수`가 `-` 면 급수 없음(길이·난이도는 N3 이상 규칙 적용).
- `뜻목록`은 그 단어의 **모든 sense**. 예문은 **대표 sense(1번) 기준으로 2개** 만든다. 1번이
  접사·관용 등으로 단독 예문이 부자연스러울 때만 다른 sense 를 쓴다.

### 출력 — 순번당 정확히 2줄 (거부 시 1줄)

```
순번|sense_no|일본어|한국어
순번|X|사유        ← 규칙 12 에 해당할 때만, 그 순번의 유일한 줄(사유 10자 이내, 예: 단독용법없음)
```

```
1|1|今週はずっと<strong class="target-word">忙しい</strong>です。|이번 주는 계속 <strong class="target-word">바빠</strong>요.
1|1|彼女は毎日<strong class="target-word">忙しく</strong>働いている。|그녀는 매일 <strong class="target-word">바쁘게</strong> 일하고 있다.
2|1|空港まで友達を<strong class="target-word">見送り</strong>ました。|공항까지 친구를 <strong class="target-word">배웅했</strong>어요.
2|1|彼は駅で家族を<strong class="target-word">見送った</strong>。|그는 역에서 가족을 <strong class="target-word">배웅했</strong>다.
```

### 규칙

1. 표제어마다 **예문 정확히 2개**, 서로 다른 상황(예: 가정 / 학교·직장, 대화체 / 서술체)으로.
   `sense_no` 는 뜻목록 안의 번호(보통 1).
2. **문장 길이(급수별, 구두점·공백 제외 일본어 글자 수 기준)**:
   - N5·N4: 8~15자
   - N3·N2·N1·급수 없음: 8~30자
   - 표제어가 5자 이상이면 상한이 (표제어 길이−4)만큼 늘어난다(긴 가타카나어 배려).
3. **한자 난이도**: 그 급수 및 그보다 쉬운 급수의 어휘·한자 위주로 쓴다(N5 예문에 N1 한자를
   넣지 않는다). N3 이상은 자연스러움을 위해 약간 상위 어휘를 섞어도 되지만 표제어 급수보다
   과하게 어려운 문장을 만들지 않는다.
4. 표제어는 **반드시 문장에 등장**하고 강조 구간 안에 있어야 한다. 활용형(연체형·과거형·て형 등)
   허용(형태소 기본형으로 검사한다).
5. 한국어 해석은 변형 A의 문체·자연스러움 규칙(직역 금지, 해요체/평서체 혼용)을 그대로 따른다.
6. **강조 태그, 일본어·한국어 각각 정확히 1개**:
   - 일본어: 표제어의 실제 활용형(오쿠리가나 포함) 전체를 감싼다. 조사(を/に/は/が 등)가
     표제어 자체의 일부가 아니면 포함하지 않는다(단, `exp` 표제어처럼 조사가 표제어 표기에
     원래 포함된 경우는 그 전체를 감싼다).
   - 한국어: 변형 A의 강조 규칙과 동일(어절 단위, 조사 제외, 어미 포함, 1곳만).
7. 고유명사·민감한 소재(정치·종교·성·폭력·질병 진단) 금지. 인명이 필요하면 흔한 이름
   (田中さん, 山田さん 등)만 쓴다.
8. 후리가나/읽기 토큰은 만들지 않는다(적용 단계에서 결정론적으로 생성).
9. 모르는 단어라도 반드시 채운다. 건너뛰기 금지(규칙 12 의 거부만 예외). 두 예문을 같은 문장으로 쓰지 않는다.
10. 일본어·한국어 문장 안에 `|` 를 쓰지 않는다.
11. **한국어 동음이의어 주의**: 뜻목록의 한국어 단어를 한국어의 다른 뜻으로 읽지 않는다. 뜻목록은
    일본어 표제어의 뜻을 한국어로 옮긴 것이다 — 예: カーン 뜻 "칸"(인명 Kahn)을 "빈칸"으로 읽고
    「表の一カーン」을 만들면 틀린다. 뜻목록이 여러 뜻으로 읽히면 표제어(일본어) 쪽 뜻을 기준으로
    문장을 쓰고, 표제어 자체가 그 상황에서 실제로 쓰이는 말인지 확인한다.
12. **한 글자·접사·약어 표제어**(庁, 原, 衆, 科, 住, 勢, -ネス, デシ- 등)는 **더 큰 단어 속에 넣어 강조하지
    않는다**(庁舎의 庁, 勢力의 勢, 眼科의 科만 강조 금지 — 적용 단계에서 "강조가 형태소 경계를
    가로지름"으로 실패한다). 그 표제어가 문장 속에서 **단독 어절로** 쓰이는 예문만 쓴다. 단독 용법이
    없으면(접두사·접미사로만 쓰이는 형태소, 약어 조각 등) 억지로 만들지 말고 그 순번은
    `순번|X|사유` **한 줄만** 출력한다(사유 1~10자, 예: `단독용법없음`, `접사전용`). 두 예문 중 하나만
    거부하는 것은 안 된다 — 둘 다 쓰거나 X 한 줄.
13. **동의어·약어 쌍 문장 복제 금지**: 같은 배치 안의 동의어·약어 쌍(共和/共和制, 短大/短期大学,
    官邸/公邸 등)에 표제어 자리만 바꾼 같은 문장을 쓰지 않는다. 쌍마다 상황·문장 틀을 다르게 한다.
    「歴史の授業でXについて学んだ。」「地図でXの位置を確認した。」 같은 틀을 여러 단어에 돌려 쓰지 않는다.
14. **문체 다양화**: 한국어가 평서(해라)체로만 쏠리지 않게, 배치 전체에서 대략 3~4문장 중 1문장은
    해요체(`~해요`, `~했어요`)나 대화체(「」 없이 말하는 투, 일본어도 です/ます·구어체)로 쓴다.
    한 단어의 두 예문은 가능하면 문체를 서로 다르게(하나는 서술체, 하나는 대화체/해요체) 한다.

## 공통 금지 사항

- 강조 태그 0개 또는 2개 이상 금지(변형 A 는 한국어 해석에만 1개, 거부 줄 `X` 에는 태그 없음).
- 다른 HTML 태그, 마크다운, 이스케이프 오류(`\"` 깨짐 등) 금지.
- 설명·서론 없이 결과 줄만 출력.
