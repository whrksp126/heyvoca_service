# 일한사전 뜻 한국어화 — 고정 프롬프트 (모든 배치 동일)

일본어 학습 사전 "heyvoca_dict_ja"의 표제어에 **한국어 뜻과 UD 품사**를 매긴다.
골격(표제어·읽기·JMdict 품사·영어 gloss·예문 원문)은 이미 결정론적으로 만들어져 있다.
너(LLM)의 역할은 **그 뜻을 한국어 사전식으로 옮기고 품사를 최종 판정하는 것**뿐이다.

입출력의 정확한 배치 파일 스키마·경로·검증 규칙은 `BATCH_FORMAT.md`를 따른다. 이 문서는
그 스키마 안에서 "어떻게 번역·판정할지"의 내용 규칙만 다룬다.

## 입력 (배치 파일, 단어당 1줄)

탭 구분 5컬럼: `순번  표제어  읽기  senses  krdict후보`.

- `senses`는 `||`로 여러 뜻(sense)을 나열하고, 각 sense는
  `sense_no:JMdict품사(,품사...):영어gloss1,gloss2,...[:일본어예문]` 형식이다
  (예문은 있을 때만, 참고용 문맥이며 번역 대상이 아니다). 색인이 sense 를 지정한 예문은 그 sense 에,
  sense 미지정 예문은 **1번 sense 에만** 붙는다 — 1번 예문이 실제로는 다른 sense 용법일 수 있으니
  gloss 를 우선한다.
- `krdict후보`는 국립국어원 한국어기초사전(krdict) 일본어 대역을 역방향으로 뒤집은
  대조표(`build/krdict_ja_reverse.json`)에서 이 표제어(일본어)로 찾은 한국어 후보다.
  `한국어단어(품사):짧은뜻풀이`를 `;`로 여러 개 나열하고(뜻풀이는 40자 이내로 잘라서 들어있음),
  후보가 없으면 `-` 한 글자다.

```
7	走る	はしる	1:v5r,vi:to run,to dash||2:v5r,vi:to drive,to operate (a vehicle)||3:v5r,vi:to stretch,to extend (e.g. a road)	달리다(동사):발을 빠르게 움직여 나아가다;뛰다(동사):빠른 걸음으로 움직이다
12	元気	げんき	1:adj-na,n:health,energy,vigor,spirits	-
23	勉強	べんきょう	1:n,vs:study,diligence,pursuit of knowledge:日本語を勉強しています。	공부(명사):학문이나 기술을 배우고 익힘;공부하다(동사):학문이나 기술을 배우고 익히다
```

## 출력 (단어당 sense 개수만큼 줄)

```
순번|sense_no|뜻1=POS1;뜻2=POS2
```

- 한 줄 = 한 (표제어, sense_no) 조합. 입력에 있던 **모든 sense에 대해 반드시 1줄 이상** 출력한다(건너뛰기 금지).
- 뜻은 `;`로 여러 개 이어 쓰고, 각 뜻 뒤에 `=POS`를 붙인다. 뜻 개수는 sense당 **1~3개**.
- 순번은 입력 그대로 복사. sense_no도 입력 그대로 복사(새로 만들거나 합치지 않는다).
- 설명·서론·마크다운 없이 결과 줄만 출력한다.

```
7|1|달리다=VERB
7|2|운행하다=VERB;운전하다=VERB
7|3|뻗다=VERB;이어지다=VERB
12|1|기운=NOUN;건강한=ADJ;활기찬=ADJ
23|1|공부=NOUN;공부하다=VERB
```

## 뜻 작성 스타일 (기존 영한사전과 통일)

기존 영한사전(`heyvoca_dict`)의 `voca_meaning.meaning` 스타일을 그대로 따른다. 예:
`run→달리다/운영하다/출마`, `happy→행복한/기쁜/만족한`, `quickly→빨리/빠른/신속히`,
`although→비록…이지만`. 이 톤·길이·어미를 일본어 사전에도 동일 적용한다.

- **품사별 어미 고정**: VERB는 `-다`(달리다, 공부하다), ADJ는 관형형 `-ㄴ/은/한`(조용한, 건강한 —
  `-하다` 종결형 쓰지 않는다), NOUN/PROPN은 명사 그대로(공부, 기운), ADV는 부사 그대로(빨리, 반짝반짝).
- **길이**: 뜻 1개당 한글 기준 **20자 이하**. 여러 뜻으로 나눠 짧게 쓰지, 긴 설명으로 늘리지 않는다.
- **괄호**: 꼭 필요할 때만 최대 1개(예: "숫돌(칼 가는 도구)" 같은 모호성 해소용). 남발 금지.
- **영어 병기 금지**: gloss를 그대로 옮기거나 영단어를 괄호에 넣지 않는다.
- **문장형 금지**: "~하는 것", "~할 때 쓰는 말" 같은 서술형·설명형 문장을 쓰지 않는다. 사전 표제어처럼 짧게.
- **일본어 원어 기준 번역**: 입력에 있는 영어 gloss는 의미 확인용 참고자료일 뿐이다. gloss를 직역하지
  말고, 그 gloss가 가리키는 **일본어 단어 자체의 실제 뉘앙스**를 한국어 대역어로 옮긴다.
  예: `静か`의 gloss가 `quiet, silent`라도 "조용한, 고요한"처럼 일본어 형용사가 실제 갖는
  어감(정적인 조용함) 기준으로 쓰고, "잠잠한"처럼 결이 다른 대역어는 피한다.
- **지시어 품사 고정**: 이것/그것/저것/여기/거기/저기/이쪽/그쪽/저쪽/이분/그분 같은 지시대명사는 항상 PRON, 이/그/저(관형사)는 DET. 같은 단어에 PRON과 NOUN을 섞지 않는다.
- **띄어쓰기**: 동사구·명사구는 한국어 맞춤법대로 띄어 쓴다("차를 마시다", "경기 종료", "그 정도"). 붙여 쓰지 않는다.
- **형용사 대역은 반드시 관형형**: JMdict 품사가 동사(v1/v5 등)여도 한국어 대역이 형용사면 관형형으로 쓴다(足りる→충분한, すごい→굉장한, 異なる→다른). `충분하다=ADJ`처럼 `-다`형 ADJ는 금지. 동사형을 남기고 싶으면 `충분하다=VERB`가 아니라 관형형 ADJ 하나로 쓴다.
- **사물 지시어**: 거기/저쪽 같은 지시어는 비유·완곡 sense에서도 PRON. 사물을 가리키는 あれ/それ/これ는 단독 "저/그/이"가 아니라 "저것/그것/이것"으로 쓴다(단독 "저/그"는 1·3인칭 대명사나 관형사 전용). "그때"는 NOUN.
- **기본어의 첫 뜻**: N5·N4 기본어의 sense 1 첫 뜻은 가장 기본적인 대역을 원래 품사 그대로 둔다(できる→할 수 있다=VERB;가능한=ADJ). 명사+동사 구는 띄어 쓴다(그 정도, 소리 지르다, 응석 부리다).
- **sense 간 중복 허용**: 서로 다른 sense의 뜻이 같은 한국어 단어로 겹쳐도 합치지 않고 각 sense에
  그대로 둔다(중복 정리는 적재 단계에서 별도 처리).

## krdict 후보 활용 규칙

`krdict후보` 컬럼은 사람이 만든 검증된 한국어기초사전 대역어이므로, **해당 sense의 의미와
맞는 후보가 있으면 새로 짓지 말고 그 후보를 우선 채택**한다. 단, 그대로 복사하지 말고
표기·어미는 이 문서의 스타일(동사 `-다`, 형용사 관형형)에 맞춘다(후보의 뜻풀이가 명사형
설명이라도 실제 사용은 동사/형용사가 맞으면 그 형태로 바꿔 쓴다).

이 후보는 "한국어 표제어 → 일본어" 방향의 사전을 거꾸로 뒤집어 만든 것이라는 한계가 있다:

- 그 일본어 단어의 **모든 sense를 덮지 않는다**. 후보가 있는 sense도 있고 없는 sense도 있다.
- **무관한 후보가 섞여 있을 수 있다**(다른 sense의 뜻이거나, 애초에 오매칭인 경우).

그래서 다음 순서로 처리한다:

1. sense별로 후보 목록을 훑어 **그 sense의 gloss·예문과 의미가 맞는 것만** 고른다.
2. 맞는 후보가 있으면 스타일만 다듬어 채택한다(뜻을 새로 짓지 않는다).
3. 맞는 후보가 없으면(후보가 `-`이거나, 있어도 이 sense와 안 맞으면) 무시하고 gloss 기준으로
   직접 작성한다 — 억지로 끼워 맞추지 않는다.
4. **후보를 억지로 전부 소진하지 않는다.** 한 sense에 후보가 여러 개 있어도 그중 이 sense와
   맞고 우리 스타일에 맞는 것만 쓰고, 나머지(다른 sense용으로 보이는 것 등)는 버린다.

예: 위 `走る` 입력에서 sense 1(`to run, to dash`)은 후보 "달리다(동사)"가 정확히 맞으므로
채택(스타일만 관형형이 아닌 동사 `-다`형 그대로: "달리다"). sense 2(`to drive, to operate a
vehicle`)는 후보 목록에 맞는 게 없으므로(후보 두 개 다 sense 1에 해당) 무시하고 gloss
기준으로 "운행하다"를 새로 짓는다.

## 품사 판정 — JMdict → UD 매핑 (기본값, 최종 판정 아님)

| JMdict 품사 | 기본 UD 매핑 | 비고 |
|---|---|---|
| `n` | NOUN | 인명·지명 등 고유명사 뜻이면 PROPN |
| `n-adv`, `n-t` | NOUN | 부사적으로 쓰여도 표제어 자체는 명사 |
| `vs`, `vs-i`, `vs-s` | NOUN 또는 VERB | 뜻이 명사형("공부")이면 NOUN, "~하다"형이면 VERB |
| `v1`, `v1-s`, `v5*`, `vk`, `vz` | VERB | 자동사/타동사 구분 없이 VERB |
| `adj-i`, `adj-na`, `adj-no` | ADJ | 뜻이 명사로 자연스러우면(예: `元気`→"기운") NOUN 예외 허용 |
| `adj-pn` | DET | `この/その/あの/どの` 류 |
| `adj-t`, `adj-f` | ADJ | |
| `adv`, `adv-to` | ADV | 의성어·의태어 포함. 독립된 감탄으로만 쓰이면 INTJ |
| `pn` | PRON | |
| `prt` | PART 또는 ADP | 종조사·간투조사(`か,ね,よ,な`)=PART. 격조사(`を,に,で,へ,から,まで,より`)처럼 한국어
  조사 "~을/~에/~에서" 형태로 옮겨지는 것=ADP |
| `conj` | CCONJ 또는 SCONJ | 대등접속(`そして,また,or`류)=CCONJ, 종속접속(`ので,のに,ば`류)=SCONJ |
| `cop` | AUX | だ/です |
| `aux`, `aux-v`, `aux-adj` | AUX | |
| `num`, `ctr` | NUM | 조수사 포함(개/마리/번째) |
| `int` | INTJ | |
| `pref`, `suf` | 상황 판단 | 접사 자체에 실질적 뜻이 있으면 그 뜻의 품사, 형식적 의미만 있으면 X |
| `exp` | 상황 판단 | 구·관용구는 전체가 기능하는 품사로(인사말=INTJ, 동사구=VERB, 형용사구=ADJ 등) |
| `unc` | X | |

**최종 품사는 반드시 한국어 뜻풀이 기준으로 재판정한다.** JMdict 태그는 출발점일 뿐이다.
예: `勉強`(vs)의 뜻이 "공부"면 NOUN, "공부하다"면 VERB — 같은 sense 안에서도 뜻마다 품사가
다를 수 있다(`元気`→"기운=NOUN; 건강한=ADJ"). `voca_meaning.pos`는 UD 15종
(`NOUN,VERB,ADJ,ADV,PRON,DET,ADP,CCONJ,SCONJ,NUM,INTJ,PART,AUX,PROPN,X`)만 허용되므로 반드시
이 목록 안에서만 고른다.

## 특수 처리 지침

- **경어(존경어/겸양어)**: 존대 자체가 단어 뜻이므로 한국어 존대어로 그대로 옮긴다
  (`召し上がる`→"드시다"[VERB], `いただく`→"받다/먹다(겸양)"가 아니라 그냥 "먹다"—괄호로
  "(높임)"·"(겸양)" 같은 주석을 달지 않는다. 대역어 자체가 이미 존대/평대를 담는다).
- **의성어·의태어**: 한국어의 대응 의성어/의태어로 옮긴다(`ワンワン`→"멍멍", `キラキラ`→"반짝반짝",
  `ドキドキ`→"두근두근"). 문장 안에서 부사로 쓰이면 ADV, 독립된 감탄사로만 쓰이면 INTJ.
- **가타카나 외래어**: 원어(영어 등)를 그대로 직역하지 말고 일본어에서 실제 쓰이는 의미로 옮긴다.
  한국어에도 같은 외래어가 흔히 쓰이면 그 표기를 쓰고(`コーヒー`→"커피"), 아니면 뜻으로 풀어 쓴다
  (`アットホーム`→"아늑한", "at home"의 직역인 "집에서"로 쓰지 않는다).
- **감탄사**: 느낌표·물음표 없이 짧은 감탄어만 쓴다(`ok`류처럼 "됐어", "이런" 등 — 문장부호 금지).
- **조사·조동사**: 한국어 조사/어미 형태로 옮기되 결합 위치를 `~` 또는 `…`로 표시한다
  (기존 영한사전 ADP 스타일과 동일: `より`→"~보다", `ので`→"…이기 때문에", `らしい`→"~인 것 같다").
  조사·조동사 자체는 활용하지 않으므로 어미 변형 없이 그대로 둔다.

## 금지 사항

1. 뜻에 영어 병기 금지 (gloss·로마자 표기 포함).
2. 괄호 설명 남발 금지 (최대 1개).
3. 뜻 1개 20자 초과 금지.
4. 문장형(서술문·설명문) 금지 — 사전식 대역어만.
5. sense_no 임의 생성/병합/누락 금지.
6. 설명·서론·마크다운 없이 결과 줄만 출력.

## 예시 (전체 흐름)

입력:
```
1	猫	ねこ	1:n:cat	-
2	静か	しずか	1:adj-na:quiet,peaceful,calm	-
3	ください	ください	1:exp,aux:please (give me)	-
4	わんわん	わんわん	1:adv-to,int:bow-wow,woof	-
5	走る	はしる	1:v5r,vi:to run,to dash||2:v5r,vi:to drive,to operate (a vehicle)	달리다(동사):발을 빠르게 움직여 나아가다;뛰다(동사):빠른 걸음으로 움직이다
```

- 5번 줄: sense 1은 후보 "달리다(동사)"가 의미와 맞으므로 그대로 채택. sense 2는 두 후보
  모두 sense 1(달리다/뛰다는 "운전하다"의 의미가 아니다)에 해당해 이 sense와 안 맞으므로
  무시하고 gloss 기준으로 새로 짓는다.

출력:
```
1|1|고양이=NOUN
2|1|조용한=ADJ;고요한=ADJ
3|1|주세요=AUX
4|1|멍멍=ADV
5|1|달리다=VERB
5|2|운행하다=VERB;운전하다=VERB
```
